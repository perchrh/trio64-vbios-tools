## 14.2 Sequencer registers: Unlock Extended Sequencer Register (UNLK_EXSR) (SR8)

Read/Write
Power-On Default: 00H
Address: 3C5H, Index 08H

Loading xxxx0110b (e.g., 06H) unlocks accessing of all the S3 extensions (SR9 - SR18) to the
standard VGA Sequencer register set. (x = don't care).

## 11.2.1 Unlocking the S3 registers (the sequence that writes SR8)

"Write code to SR8 to provide access to the S3 extended Sequencer registers"; the code is
xxxx0110b, 06H for example. (The same section's account of the DPMS use of SRD repeats: "the
bit pattern xxxx0110b must be written to the SR8 register to unlock access to the SRD
register.")
