# DMT 1.0 Rev. 10: 640 x 480 at 60 Hz (extract)

Source: VESA and Industry Standards and Guidelines for Computer Display Monitor Timing (DMT)
Version 1.0, Revision 10, 29 October 2004,
[`standards/vesa/VESA-DMT-1.0-Rev10.pdf`](../../../standards/vesa/VESA-DMT-1.0-Rev10.pdf), page 10
(document page "Page 10 of 62"). Used for milestone-4 mode 101h timings and MQ-16 (border).

ASCII paraphrase. Prefer the PDF on any conflict. The sheet marks this industry timing
"For Reference Only - Not VESA Standard".

## Summary line (Standards and Guidelines Summary, page 3)

640 x 480, 60 Hz, horizontal 31.5 kHz, pixel 25.175 MHz, Industry Standard.

this extract settles that DMT's 640x480@60 figures include them.
